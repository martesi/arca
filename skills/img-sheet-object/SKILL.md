# Object Sheet

Use the available image-generation capability directly. Create the requested image rather than returning only a text prompt unless the user explicitly asks for prompt text.

Combine **all distinct items visible across the provided reference images into a single image**. Preserve each item's appearance, colors, materials, proportions, markings, and important details. **Do not omit, merge, duplicate, redesign, or invent anything.**

Arrange everything in a **dense, space-efficient composition**, scaling and rotating items as needed while keeping them fully visible and recognizable. Minimize empty space, use tight but clean spacing, and avoid unnecessary overlap or cropping. Keep relative scale sensible where possible. Use a simple neutral background and consistent lighting. No text, labels, borders, or decorative elements.
