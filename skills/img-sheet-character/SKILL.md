# Character Sheet

Use the available image-generation capability directly. Create the requested image rather than returning only a text prompt unless the user explicitly asks for prompt text.

Create a professional, realistic **16:9 orthographic character reference sheet** from the provided reference image(s).

Treat all references as the **same subject photographed from different angles**. Reproduce only what is visible in the references: exact identity, face, skin tone, hair, body proportions, clothing, shoes, accessories, tattoos, scars, and other distinguishing features. Do not invent, redesign, omit, or alter details. Keep identity, anatomy, outfit, and proportions perfectly consistent across every view.

**Modify before rendering:** neutral expression; empty hands; remove handheld objects. If topless, preserve visible abdominal definition and V-cut from the reference.

**Anatomy:** correct limbs, hands, fingers, and proportions; no duplicates, omissions, distortions, or unintended cropping. Keep head, hands, and feet fully visible in body views.

**Style:** match the reference’s realism, texture, colors, and rendering. Use consistent flat studio lighting across all views. Crisp, high-detail, print-ready output.

**Background:** solid `#EAE7DC` only; no gradient, environment, or background cast shadows. No text, labels, borders, frames, grids, guides, measurements, logos, watermarks, or UI.

**Layout — 5 horizontal columns:**

- Columns 1–4: full-body **front, left profile, right profile, back**, standing relaxed A-pose, orthographic, same scale/head height.
- Column 5: **front, ¾ left, ¾ right portraits**, stacked vertically, equal head size, crop, and shoulder width, filling the sheet height.

Use tight margins where needed without overlap. Maximize subject size and detail while preserving the complete layout.
