# Grilling

Before selecting the implementation stack or scaffolding the project, load and follow the current upstream `grilling` skill:

`https://raw.githubusercontent.com/mattpocock/skills/refs/heads/main/skills/productivity/grilling/SKILL.md`

Use it to stress-test the product, architecture, and workflow decisions until the user confirms a shared understanding. Gather facts from the repository, environment, and available tools yourself; reserve questions for decisions that actually belong to the user.

If the runtime cannot load a remote skill directly, fetch that `SKILL.md` and follow it as an external instruction reference. Do not vendor a copy into this skill unless explicitly requested, so the upstream workflow can stay current.
