# Grilling

At the start of the project interview, load and follow the current upstream `grilling` skill:

`https://raw.githubusercontent.com/mattpocock/skills/refs/heads/main/skills/productivity/grilling/SKILL.md`

Use it to uncover the purpose, user, pain, current workaround, constraints, and success criteria before converging on architecture. Ask one high-value unresolved question at a time. Gather facts from the repository, environment, and available tools yourself; reserve questions for decisions that actually belong to the user.

If the runtime cannot load a remote skill directly, fetch that `SKILL.md` and follow it as an external instruction reference. Do not vendor a copy into this skill unless explicitly requested, so the upstream workflow can stay current.
